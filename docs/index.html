UniversalController

Контроллер CAN FD / LIN для доработок автомобиля: читает сигналы шины и управляет нагрузками по вашим правилам. Настраивается в браузере, программировать не нужно. Внутри сниффер, а поиск сигналов ведёт Claude.

Где купить Инструкция Монитор и плагин на GitHub

Что он умеет

Правила вместо кода

Каждый выход включается по условию: до четырёх сравнений с И/ИЛИ по входам, сигналам CAN/LIN и другим выходам. Кнопки без фиксации, работа по зажиганию, задержки, плавный пуск, ШИМ.

Кадры в шину как в CAN Hacker

Байты прямо в строке, период, условие запуска и задержка пуска для строгой очерёдности. Например: открыть сессию UDS, затем включить ДХО.

Сниффер CAN / CAN FD / LIN

Живой поток на ноутбуке, вид по ID с подсветкой изменений, запись в файл, разбор кадра по битам.

Поиск сигналов с Claude

Открытый плагин для Claude Code: ИИ даёт инструкции на экран («подними обороты до 2000»), пишет шину и сам находит нужный кадр и бит, потом показывает живое значение для проверки.

Не разряжает аккумулятор

Сон при тишине в шине и на входах, пробуждение от первого кадра или от входа.

Обновление по USB

Прошивка обновляется кнопкой со страницы настроек, настройки сохраняются.

Где купить и как связаться

Платы поставляются прошитыми, с инструкцией. Ссылки на магазины появятся здесь по мере открытия витрин.

Пока вопросы и заказ: через Issues репозитория. Укажите плату, марку и год машины и задачу, подскажем, подойдёт ли и какие сигналы понадобятся.

Контроллер предназначен для дополнительного оборудования. Цепи безопасности (подушки, ABS, рулевое, тормоза) не поддерживаются. Установку выполняет специалист по автоэлектрике, питание через предохранитель.

Монитор и плагин

Программа-монитор для Windows (обзор, настройки, сниффер, совместная работа) и плагин для Claude Code лежат в открытом репозитории github.com/ayvengo61/uc-can-hunt. Установка плагина: /plugin marketplace add ayvengo61/uc-can-hunt, затем /plugin install uc-can-hunt@uc-tools. Для работы с Claude нужны Claude Code (платный план Claude Pro/Max или оплата через API) и Python; остальное работает без них.
