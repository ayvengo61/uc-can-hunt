UniversalController

A CAN FD / LIN controller for car add-ons: it reads bus signals and drives loads by your rules. Set up in a browser, no coding. A sniffer is built in, and Claude guides the signal hunting.

Where to buy Guide Monitor and plugin on GitHub

What it does

Rules instead of code

Every output switches by a condition: up to four AND/OR comparisons on inputs, CAN/LIN signals and other outputs. Momentary buttons, ignition-gated modes, delays, soft start, PWM.

Frames to the bus, CAN Hacker style

Bytes right in the row, period, trigger condition and a start delay for strict ordering. For example: open a UDS session, then switch the DRL on.

CAN / CAN FD / LIN sniffer

Live stream on the laptop, by-ID view with change highlighting, recording to file, bit-level frame view.

Signal hunting with Claude

An open Claude Code plugin: the AI puts instructions on the screen ("hold 2000 rpm"), records the bus, finds the frame and bit, then shows the live value for confirmation.

No battery drain

Sleeps when the bus and inputs are quiet, wakes from the first frame or an input.

USB updates

Firmware updates from the settings page; settings are preserved.

Where to buy, contact

Boards ship flashed, with a guide. Store links will appear here as the storefronts open.

Until then, questions and orders go through the repository Issues. Mention the board, your car make and year and the task; we will tell you whether it fits and which signals you will need.

The controller is for accessory circuits. Safety systems (airbags, ABS, steering, brakes) are not supported. Installation by an auto-electrics professional, fused supply.

Monitor and plugin

The Windows monitor (overview, settings, sniffer, collaboration) and the Claude Code plugin live in the open repository github.com/ayvengo61/uc-can-hunt. Plugin install: /plugin marketplace add ayvengo61/uc-can-hunt, then /plugin install uc-can-hunt@uc-tools. Working with Claude needs Claude Code (a paid Claude Pro/Max plan or API billing) and Python; everything else works without them.
