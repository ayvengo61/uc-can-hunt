# uc-can-hunt — поиск сигналов в CAN машины вместе с Claude

Плагин для Claude Code. Вы сидите в машине с ноутбуком, контроллер UniversalController (G4, H723 или H503)
слушает CAN-шину, монитор показывает вам страницу «Совместная работа», а Claude даёт короткие инструкции
(«подними обороты до 2000 и держи»), пишет шину, разбирает запись и находит нужное поле: обороты, скорость,
педали, селектор, кнопки на руле, двери, замки, свет, температуру, топливо. В итоге — описание поля и строка
для конфига прошивки.

```
машина ── CAN ── контроллер (прошивка со сниффером) ── USB ── UC_<плата>_Monitor.exe ── страница /assist (вы)
                                                                       │
                                                      Claude Code: навык can-hunt (car.py, canhunt.py)
```

**Подробная инструкция для новичка (скачать, запустить, пользоваться): [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).**

## Что нужно

- Windows 10/11 (монитор — exe на .NET Framework 4.x, он есть в системе).
- Python 3.10+ и пакеты: `pip install numpy pillow`.
- Claude Code (любой аккаунт).
- Контроллер UniversalController (G4, H723 или H503). Платы поставляются уже прошитыми; прошивки в пакет не входят.
- Подключение к CAN машины: CAN-H / CAN-L (разъём OBD-II — контакты 6 и 14) или напрямую к нужной шине.

## Установка плагина

Вариант 1 — из GitHub (репозиторий https://github.com/ayvengo61/uc-can-hunt, маркетплейс лежит в нём же):

```
/plugin marketplace add ayvengo61/uc-can-hunt
/plugin install uc-can-hunt@uc-tools
```

Вариант 2 — из папки без GitHub (только на один сеанс):

```
claude --plugin-dir "<путь к этой папке>"
```

Вариант 3 — навсегда без маркетплейса: скопировать эту папку целиком в `%USERPROFILE%\.claude\skills\`.

После установки навык доступен как `/uc-can-hunt:can-hunt`, но вызывать его по имени не обязательно: достаточно
сказать Claude «поехали, ищем обороты», «найди кнопку на руле», «подключись к машине».

## Как начать

1. Подключите контроллер к CAN машины и по USB к ноутбуку, включите зажигание.
2. Запустите монитор своей платы: `monitor/G4/UC_G4_Monitor.exe`, `monitor/H723/UC_H723_Monitor.exe` или
   `monitor/H503/UC_H503_Monitor.exe`. В окне монитора нажмите «Совместная работа»: откроется страница `/assist`.
   Нажмите жёлтую плашку «Звук выключен», чтобы слышать новые инструкции.
3. В Claude Code скажите, что ищем. Claude проверит связь, включит сниффер, начнёт запись и даст первую инструкцию.
4. Делайте ровно то, что написано на странице, и нажимайте кнопку под инструкцией. Если что-то не так — поле
   «Сообщение для Claude».

Найденные поля Claude записывает в папку проекта `can_hunt_found/<марка_модель_год>.md`: описание поля, строка для
конфига прошивки и запись в формате DBC.

## Безопасность

- Двигатель и обороты — только на стоянке: P (нейтраль), ручник, никого перед машиной и за ней.
- За рулём в движении страницу не читать и кнопки не нажимать: скорость и колёса пишем с пассажиром или разбираем
  поездку потом.
- Сниффер слушает шину молча (Bus Monitoring) и ничего в неё не отправляет. Передача кадров — отдельный, осознанно
  включаемый режим, только на стоянке.

## Состав

- `skills/can-hunt/` — навык: `SKILL.md` (методика), `SPEC.md` (контракт монитора), `PLAYBOOK.md` (сценарии по
  сигналам), `scripts/car.py` (команды монитору), `scripts/canhunt.py` (анализ записей), `scripts/ask_chain.py`.
- `monitor/<плата>/` — монитор: exe + страницы (дашборд, настройки, сниффер, совместная работа), `README.txt`.
  Записи сессий монитор кладёт рядом с собой в `can_sessions/`.

Исходники прошивок и мониторов — в проекте UniversalController (не входят в плагин).
